How the recordings were made

The unmodified JavaWiz 2.3.1 backend recorded the real java.util.concurrent.ConcurrentHashMap on Eclipse Temurin 25.0.5+8. The bucket view on this page reads those heap records; it does not run a JavaScript implementation of the map.

For resizing, the harness temporarily holds bucket monitors to stop two real writer threads at reproducible checkpoints. JavaWiz observes the main thread and the shared heap. The recording includes both active resize workers, forwarding nodes, a lookup during resizing, and the final table switch.

These are selected heap snapshots, not an instruction trace of every worker. The explanatory labels follow the OpenJDK implementation. Empty buckets also receive forwarding nodes during transfer.
